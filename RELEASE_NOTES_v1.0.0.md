# GameVault v1.0.0 - First Stable Release

GameVault v1.0.0 is the first stable milestone of the self-hosted game collection and backup inventory.

## Highlights
- PostgreSQL-backed Docker application with responsive UI
- PS2, PS3, PS4 and Xbox 360 collection management
- Game Collector XML and documented PS4 Package XLSX imports
- IGDB metadata, local cover caching and resolver diagnostics
- PS4 CUSA/ORBISPatches resolution and update-status comparison
- Base Game, Patch and DLC inventory with normalized package versions
- Manual game/package metadata correction
- Data-quality analysis
- Duplicate comparison, merge and persistent exclusions
- Region, format, edition, storefront, tags and notes
- JSON library export

## Next
v1.1 starts Console Inventory, beginning with PlayStation 3 using read-only FTP plus optional webMAN MOD enrichment.
