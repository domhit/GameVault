# GameVault v0.9.2

- Effective local PS4 version is the highest version from Game **or** Patch packages.
- Base games already including a newer revision (for example Game 1.02 without a separate patch) now participate correctly in update comparison.
- Every backup package has **Bearbeiten** to manually correct type, version, location, size and decision.
- DLC versions are always empty.
- GameVault deliberately does not infer versions from filenames.
- Existing v0.9.1 single-version database and import documentation remain unchanged.
